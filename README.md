# CronPilot Navigation Database

Offline navigation reference data for CronPilot Android.

## Data Source

Navigation reference data is derived from [OurAirports](https://ourairports.com/data/).

OurAirports provides its datasets as Public Domain. The data may be used, modified and redistributed.

## Distribution

The navigation database is distributed as `nav_references.dat` through GitHub Releases.

CronPilot Android users can download updated navigation references using the **UPDATE NAV DATA** function.

## Important Safety Notice

**NOT FOR REAL-WORLD FLIGHT NAVIGATION.**

OurAirports data is community-maintained and may be incomplete, inaccurate or outdated.

CronPilot is not a certified aviation navigation system. Always use official, current aeronautical information for operational flight decisions.

CronPilot is not affiliated with or endorsed by OurAirports.
